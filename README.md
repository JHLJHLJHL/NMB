# 멀미마요

여객선 출항 전 해상 상태, 풍랑특보, 멀미 위험을 한눈에 확인하는 무료·무가입 웹 서비스의 지도형 앱 스케치입니다.

## 현재 범위

- 포항·포항(영일만) ↔ 울릉(도동)·울릉(사동) 4개 운항편
- 기본 5개 항로 지점과 지도 확대 시 30분 간격 상세 지점
- OpenStreetMap의 실제 여객선 점선 항로를 따르는 경로와 핀 배치
- 출발지에서 도착지까지 하나의 점이 전 구간을 흐르는 항로 애니메이션
- 지점별 예상 시각, 파고, 풍속, 풍향
- 파고·풍속 색상 범례와 파고 기준 멀미 위험 5단계 Lucide 얼굴 아이콘
- 6일 예보 탐색: 1~3일은 상세, 4~6일은 낮은 해상도의 전망으로 구분
- 엘도라도EX호(대저페리)·뉴씨다오펄호(울릉크루즈) 공식 홈페이지와 여객선 예매 링크
- 풍랑주의보·풍랑경보 표시 영역
- 모바일 우선 반응형 레이아웃

현재 화면의 수치는 디자인 검토용 예시이며 실제 기상 데이터가 아닙니다.

## 실행

별도 빌드는 필요하지 않습니다. ES 모듈을 사용하므로 프로젝트 루트에서 `dist` 폴더를 정적 파일 루트로 지정해 실행하세요.

```bash
node --test tests/route-model.test.mjs
```

## 다음 단계

기상청 기상특보·해양예보·해양부이 API와 KOMSA 공식 운항정보를 연동하고, 전국 여객선 항로를 데이터 파일로 분리해 확장합니다. Windy API 및 Windy 데이터는 사용하지 않습니다.
