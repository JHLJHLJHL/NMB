# 멀미마요

여객선 출항 전 해상 상태, 풍랑특보, 멀미 위험을 한눈에 확인하는 무료·무가입 웹 서비스의 인터랙티브 앱 스케치입니다.

## 현재 범위

- 포항 ↔ 울릉도 항로
- 출항 판단 요약과 멀미 위험
- 풍랑주의보·풍랑경보 영역
- 시간별 풍향, 풍속, 파고, 파주기
- 항로 방향, 날짜, 지도 레이어, 시간대 선택 상호작용
- 모바일 우선 반응형 레이아웃

현재 화면의 수치는 디자인 검토용 예시이며 실제 기상 데이터가 아닙니다.

## 실행

별도 빌드나 설치 없이 `dist/index.html`을 브라우저에서 열 수 있습니다. 로컬 HTTP 서버를 사용하는 경우 프로젝트 루트에서 `dist` 폴더를 정적 파일 루트로 지정하세요.

## 다음 단계

기상청 기상특보·해양예보·해양부이 API와 KOMSA 공식 운항정보를 연동하고, 전국 여객선 항로를 데이터 파일로 분리해 확장합니다. Windy API 및 Windy 데이터는 사용하지 않습니다.
